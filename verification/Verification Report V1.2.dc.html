Defects the harness itself exposed — both fixed in V1.2
Wiring the integration tests revealed that the page never loaded incommon-core.js (missing script reference — every core-backed feature silently ran a no-op fallback), and that UI updates never triggered the debounced persist (the runtime invokes componentDidUpdate without prevState, so a guard skipped the write forever). Both are repaired and now held down by IT1, IT2b, and IT8 — a concrete demonstration of why executed tests, not displayed values, are this report’s evidence standard.
Re-run it: open Test Runner V1.2.dc.html over any static server (it auto-runs and prints the SHA-256 of the sources under test), or node handoff/run-tests-node.js for the pure half. Instructions: handoff/README-RUN-LOCALLY.md.

5 AI grounding — Stella §10 · enforced, tested
The audit’s central finding: V1’s grounding was advisory — the UI rendered citation chips but accepted uncited replies, and one scripted branch leaked numerology with the chart scope off. V1.2 makes the contract enforced: every live reply must carry a SOURCES line whose chips resolve, via a fixed registry, to real enabled sources — or the reply is withheld with a visible notice and a scripted fallback. Both audit reproduction cases are now regression tests (S1/IT5, IT4). A model-processing consent modal gates the first live call; declining keeps Stella scripted-only.
