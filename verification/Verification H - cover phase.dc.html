The cover phase
Group H only, for app/cover.html. Nothing else in this suite loads that page: every other phase points at the app through SRC, so until this existed the first screen a visitor meets had no gate at all. H2 is the row it exists for. The cover is a raytracer, and a shader that fails to compile does not throw: the loop runs, the first frame lands, __EH_LIVE goes true and the reveal fires over a canvas painting nothing. So this phase reads the drawing buffer back rather than asking whether the page booted.
This browser cannot create a WebGL context at all, so H1 cannot pass and a red result from it says nothing about the build. The usual cause is a GPU process that has given out after many contexts in one session: it reports GL_VENDOR = Disabled and BindToCurrentSequence failed. Restart the browser and run this phase in a fresh window.
