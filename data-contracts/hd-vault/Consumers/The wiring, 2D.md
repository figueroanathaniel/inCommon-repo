# The wiring, 2D

The SVG wiring on My Charts, page Human Design, in both shells, and the detail
sheet a press opens.

| Reads | For |
|---|---|
| `hdChart().defined`, `activeChannels`, `acts` | centres lit, channel halves by side, gates |
| `hdChart().gates` | the Activated Gates list (one line per gate: [[D-08 One line per gate in the gate list]]) |
| `hdProfile()` | the profile tile |
| `hdChart().type`, `authority`, `strategy`, `definition` | the type card and the four tiles |
| `HDAtlas` | names and writing on the sheet |
| `hdSelOf()` / `hdSel` shapes | what a press opens ([[Chart address]]) |

Computes nothing of its own. Sees: [[HD chart]], [[Activation]].
