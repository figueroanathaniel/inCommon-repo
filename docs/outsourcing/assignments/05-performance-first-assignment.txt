THE ORDER, BECAUSE OF THE GRAPHICS UPDATE
Workstream 4 is landing a large graphics update. It changes the weight and
the frame cost of the 3D stages and the cover, so anything measured before
it lands is partly out of date afterwards. So:
  1. Measure main now (STEP 2 of your brief) and record it as "baseline A,
     main c259e80". This is still worth having: the boot path, the bundle
     and the fonts are not what the graphics update changes.
  2. Do STEP 3 (the ranked list) now, and mark each item "safe now" or
     "after graphics". Safe now means it touches none of: app/cover.html,
     the scene files, three.*.js, the code in the app file that mounts or
     sizes a stage.
  3. Implement only the "safe now" items before the graphics update merges.
  4. When it merges, measure again as "baseline B", and only then start the
     "after graphics" items.
