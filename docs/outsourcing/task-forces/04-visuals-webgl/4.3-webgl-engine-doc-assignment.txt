  a. The deploy folder is written deploy/<current>/, the value under

  b. Each module is named by its own file: app/chart-scene.js (ChartScene),
     app/hd-scene.js (HDScene), app/cycle-scene.js (CycleScene),
     app/body-globes.js (BodyGlobes), app/flight.js (Flight).

     from the same calculation the 2D view reads: _csModel from placedRows,
     natalAspects() and CAT_COLOR; _hsModel from hdChart(); the Cycle Audit
     from cycleSceneModel(). The one position a scene asks for itself comes
     through the app's own lonOf() or cyLon() (opts.lonAt). CLAUDE.md: "The

     "The Cycle Audit is drawn four ways".

     no scene, renderer or engine module holds a client.
  e. There is no client write to oracle_readings, and none is proposed. That
     table is written only by the Oracle edge function with the service
     role; server/oracle/schema.sql gives app users the one select policy
     "read own oracle readings". A reading reaches the page through
     oracleRead() and is kept on the device by oracleKeep().
  f. No dash of any kind, "astral body" in prose, no "bodygraph" in a
     heading (check-competitor-surface.js walks docs/).
