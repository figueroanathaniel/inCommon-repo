TASK 3. TWO FINDINGS FROM THE 27 OCTOBER LATENCY SWEEP
  Measured on main under SwiftShader; please confirm on a real GPU.
  a. Freezes come from synchronous WebGL queries during program link
     (getShaderInfoLog, getProgramParameter). Each scene turns
     renderer.debug.checkShaderErrors off only when GFX.ios is true
     (chart-scene.js, cycle-scene.js and hd-scene.js, one line each). Turn it
     off on every platform in production, and keep it on where a test asks
     for it, so a broken shader is still caught (H2 reads pixels, so it
     still catches one that paints nothing).
  b. The quality ladder steps down and never steps back up within a visit.
     After #93, three late frames drop a rung. Add a recovery rule (for
     example, a sustained run of on time frames raises one rung, with
     hysteresis so it cannot oscillate), and a lifecycle or VM row that
     proves it climbs back and does not flap.
