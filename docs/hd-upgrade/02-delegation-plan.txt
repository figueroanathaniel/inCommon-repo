1. HOW A TASK IS DELEGATED
-----------------------------------------------------------------------------
Each assignment file names the outcome, the files the workstream owns for it,
what it depends on, the tests and evidence required, and what counts as done.
The primary builds it on its own branch and opens a pull request; the
secondary reviews it independently; the tertiary answers narrow questions or
runs checks. Nobody reviews their own work. The rules for helpers (the browser
runner, shared seats, blind review, the helper log) are "Helpers" in
00-README.md and apply unchanged.

Status moves DRAFT, AWAITING OWNER APPROVAL, READY, ISSUED, DONE. READY means
it can be handed over; ISSUED means the agent actually has it. A name in the
roster does not start an agent: each file is pasted into that agent's working
session, or handed over through whatever integration it has.

    Who is it, and is it paid, volunteer or a professional engagement?
